## 🎯 What This App Will Do

### 📈 Graph View

- Draws graphs in real time against a reference lap
- User can choose the reference from a **file**, **session best**, or **all-time best**
- Session best is saved across reference reloads from a file
- All-time best is saved per car, per track for the user
- User can choose which car they're tracking
- Tracks the user by default
- Zoom into specific "sectors"
- **Compare mode** — shows the delta between the current lap and the reference lap
- Customizable layouts
- This view includes graphs only
- Auto-saves the last X laps (configurable by the user)

### 🗺️ Map View

- Shows a map of 2+ laps loaded from a file, with the racing lines each car took
- Interactive — zoom, pan, and explore
- Works with all in-game maps and layouts
- Bottom panel includes info/controls

### 🏆 Championship View

- Shows all drivers in a lobby plus their position on a map
- Clicking a driver shows all available status info about them
- Room for some nice QoL features
- Tire state, Lap times, Car state, General info (car, class, name), Fuel levels

### 🛠️ General Requirements

- Automatic setup on Linux (aside from the Steam portion)
- Smooth, guided onboarding
- Solid UI/UX
- Deep customizability
